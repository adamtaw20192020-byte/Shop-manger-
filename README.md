# إدارة المحل — نسخة Flutter

هذا مشروع Flutter كامل يعيد بناء تطبيق "إدارة المحل" (كان أصلاً مبنيًا بـ Expo/React Native)
بنفس الشاشات والمنطق:

- **الرئيسية**: ملخص يومي، إحصائيات سريعة، اختصارات، تنبيه المخزون المنخفض، آخر العمليات.
- **المبيعات**: تسجيل/تعديل/حذف عمليات البيع مع خصم تلقائي من المخزون.
- **المشتريات**: تسجيل/تعديل/حذف عمليات الشراء مع زيادة المخزون وتحديث سعر الشراء.
- **الأصناف**: إضافة/تعديل/حذف الأصناف، بحث، وترتيب (بالاسم / الأقل مخزونًا / الأعلى سعرًا).
- **التقارير**: تصفية حسب اليوم/الأسبوع/الشهر/فترة مخصصة، مع رسوم بيانية بسيطة وملخص العمليات.

البيانات تُخزَّن محليًا على الجهاز (عبر `shared_preferences`)، تمامًا كما كان التطبيق الأصلي
يستخدم `AsyncStorage` — لا حاجة لأي خادم أو اتصال إنترنت.

## كيفية التشغيل

هذا المجلد يحتوي الآن على **مشروع Flutter كامل جاهز للبناء**، بما فيه:

- `lib/` — كل كود Dart (الشاشات، المنطق، التصميم).
- `android/` — مشروع Android كامل (Gradle، AndroidManifest، MainActivity بلغة Kotlin،
  أيقونات مولّدة من شعارك بكل الأحجام القياسية).
- `assets/icon/app_icon.png` — شعار "Happy Birds 2" المستخدم كأيقونة.

### ملف واحد ناقص (`gradle-wrapper.jar`)

كل ملفات Gradle نصية (build.gradle, gradlew, gradle-wrapper.properties...) موجودة،
لكن **ملف `android/gradle/wrapper/gradle-wrapper.jar`** هو ملف ثنائي (binary) يوزَّع مع
Flutter SDK نفسه، ولا يمكنني توليده هنا لعدم وجود اتصال إنترنت في بيئة التنفيذ عندي.

**الحل بأمر واحد فقط**، تنفذه مرة وحدة على جهازك بعد فك ضغط المجلد (شرط أن يكون
Flutter مثبت عندك):

```bash
cd shop_manager_flutter
flutter create .
```

هذا الأمر آمن على مشروع موجود مسبقًا: يكمّل فقط الملفات الناقصة (مثل الـ jar) ويطابق
إصدارات Gradle/AGP مع نسخة Flutter عندك بالضبط، بدون ما يلمس `lib/` أو `pubspec.yaml`
اللي جهزتهم مسبقًا.

### ثم:

```bash
# ثبّت الحزم
flutter pub get

# ولّد أيقونة التطبيق (اختياري، الأيقونة موجودة مسبقًا لكن هذا يضيف Adaptive Icon)
flutter pub run flutter_launcher_icons

# شغّل على محاكي أو جهاز حقيقي
flutter run

# أو ابني APK مباشرة
flutter build apk --release
```

الـ APK الناتج بيكون موقّع مبدئيًا بمفتاح debug — لو بدك تنشره على المتجر، لازم تسوي
keystore خاص فيك وتربطه بـ `android/app/build.gradle` (قسم `signingConfigs`).


> ملاحظة: اسم الحزمة الأصلي في Android كان `com.tayouralsaida2.shopmanager` — استخدم نفس
> الـ `--org` أعلاه إذا أردت نفس معرّف التطبيق بالضبط.

## هيكل الكود

```
lib/
  main.dart                 نقطة الدخول: الثيم، الاتجاه RTL، اللغة العربية
  models/models.dart        Product / Sale / Purchase
  state/shop_state.dart     كل منطق الأعمال (إضافة/تعديل/حذف، خصم وزيادة المخزون، التخزين المحلي)
  theme/app_colors.dart     ألوان التصميم (منسوخة من constants/colors.ts الأصلي)
  widgets/shop_ui.dart      عناصر واجهة مشتركة (Header, StatCard, أزرار, نوافذ التأكيد...)
  widgets/formatters.dart   تنسيق العملة والتاريخ بالعربية
  screens/                  الشاشات الخمس + شريط التبويبات السفلي
```

## ما تم نقله بالضبط

- كل منطق `ShopContext.tsx` (بما فيه حالات تعديل/حذف المبيعات والمشتريات وتأثيرها على
  المخزون، وبيانات البداية الافتراضية لسبعة أصناف) منقول حرفيًا في `shop_state.dart`.
- نفس الألوان والتخطيط العام لكل شاشة قدر الإمكان ضمن حدود عناصر Flutter القياسية
  (بدون مكتبات أيقونات خارجية — استُبدلت أيقونات Feather بأيقونات Material المكافئة).
- التطبيق الأصلي لم يتضمن منطق مزامنة مع الخادم (`artifacts/api-server`) داخل شاشات
  المحل نفسها — كانت البيانات محلية بالكامل، لذلك هذه النسخة كذلك.

## بناء APK تلقائيًا عبر GitHub

1. ارفع المشروع إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. اختر **Build Android APK**.
4. اضغط **Run workflow**.
5. بعد انتهاء البناء افتح تشغيل الـWorkflow ثم قسم **Artifacts**.
6. نزّل `shop-manager-apk` وستجد داخله ملف APK الجاهز للتثبيت.

ملحوظة: ملف Workflow يعيد إنشاء ملفات Android الناقصة تلقائيًا قبل البناء، لذلك لا تحتاج إلى تثبيت Android Studio على الهاتف.
